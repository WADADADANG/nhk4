# 🌐 คู่มือการตั้งค่าใช้งาน Proxy บน NodeHotkey

คู่มือนี้จะสอนวิธีตั้งค่าใช้งาน **Proxy** เพื่อซ่อน IP เน็ตบ้าน ป้องกันการโดนแบน และลดอาการแลค/ปิง โดยใช้โปรแกรมฟรีอย่าง **Cloudflare WARP (1.1.1.1)** หรือ Proxy ทั่วไป

---

### ⚠️ สิ่งที่ต้องเตรียมก่อนเริ่ม:
ติดตั้งและเตรียมโปรเจกต์ NodeHotkey ให้เรียบร้อย (อ่านวิธีติดตั้งเพิ่มเติมได้ที่ [README.md])

---

## 🛠️ ขั้นตอนที่ 1: ตั้งค่าโปรแกรม Cloudflare WARP (Local Proxy)

1. เข้าไปที่เว็บไซต์ **[https://one.one.one.one](https://one.one.one.one)** ดาวน์โหลดและติดตั้งโปรแกรมให้เรียบร้อย
2. เปิดโปรแกรม **Cloudflare WARP** ขึ้นมา
3. คลิกไอคอน **รูปเฟือง (⚙️ Settings)** ➔ เลือก **Preferences / Settings**
4. เลือกหัวข้อ ปรับโหมด **Mode** ให้เป็น **Local Proxy**
5. คุณจะเห็นช่อง **Proxy Listener Port** แสดงเป็น **`40000`** (นี่คือพอร์ต Proxy ประจำเครื่องคอมพิวเตอร์ของคุณ)

---

## 🎮 ขั้นตอนที่ 2: ใส่ค่า Proxy ใน NodeHotkey (Web Dashboard)

1. เปิดใช้งานโปรแกรมโดยการดับเบิลคลิกไฟล์ **`NodeHotkey Launcher.bat`** (หรือ **`3 start.bat`**)
2. หน้าเว็บควบคุม **[http://localhost:3000](http://localhost:3000)** จะเปิดขึ้นมาบนเบราว์เซอร์อัตโนมัติ
3. มองไปที่หัวข้อ **Client Control Center (การ์ดจอ Client 1 - 8)**
4. คลิกไอคอน **รูปฟันเฟือง (⚙️)** บนการ์ดจอ Client ที่คุณต้องการตั้งค่า จะมีหน้าต่าง Pop-up เด้งขึ้นมา
5. ในหน้าต่างตั้งค่า คุณสามารถเลือก **Browser Engine** (Google Chrome, Microsoft Edge, Mozilla Firefox) และในช่อง **IP / Proxy Settings** ให้กรอกข้อมูล:
   ```text
   http://127.0.0.1:40000
   ```
   *(หรือหากใช้ Proxy รายเดือน ให้กรอกเป็น `http://ip:port` หรือ `http://ip:port:user:pass`)*
6. กดปุ่ม **💾 Save Changes** เพื่อบันทึกข้อมูล

---

## 🚀 ขั้นตอนที่ 3: เปิดใช้งานและทดสอบว่า Proxy ทำงานหรือไม่

1. **เปิดหน้าต่างจอที่ตั้งค่า:**
   - หากจอนั้นปิดอยู่: กดปุ่ม **`➕ Launch`** เพื่อเปิดจอขึ้นมาได้ทันที
   - หากจอนั้นเปิดค้างไว้อยู่: กดปุ่ม **`❌` (ปิดจอ)** ก่อน แล้วกด **`➕ Launch`** ใหม่อีกครั้ง เพื่อให้เบราว์เซอร์โหลด Proxy ชุดใหม่
2. **ทดสอบเปิดเกม:** เบราว์เซอร์จะเปิดหน้าเว็บเกมได้ตามปกติโดยไม่มีอาการติดขัด
3. **เช็ก IP ใหม่:** ลองเปิดแท็บใหม่ในเบราว์เซอร์จอนั้นแล้วเข้าไปที่เว็บไซต์ **[https://ipv4.webshare.io](https://ipv4.webshare.io)** หรือ **[https://whoer.net](https://whoer.net)** คุณจะเห็นว่า IP Address เปลี่ยนเป็น IP ใหม่เรียบร้อยแล้ว! 🎯

---

💡 **หมายเหตุเพิ่มเติม:**
- หากใช้ Cloudflare WARP ฟรี 1 เครื่อง ให้ใส่ `http://127.0.0.1:40000` ให้ทุกจอได้เลย (จะช่วยซ่อน IP บ้านและลดปิง)
- หากต้องการให้แต่ละจอเป็นคนละ IP ไม่ซ้ำกันเลย (8 จอ 8 IP) ต้องใช้ Proxy แบบเช่ารายเดือนมาใส่แยกพอร์ต/IP ในแต่ละจอครับ
